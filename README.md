# n8n-nodes-faxtofax

Send and receive faxes in [n8n](https://n8n.io) with [FaxToFax](https://faxtofax.com).

## Install
In n8n: **Settings → Community Nodes → Install**, enter `n8n-nodes-faxtofax`.

## Credentials
Create an API key in FaxToFax under **Settings → API keys** (monthly plans), then add a **FaxToFax API** credential in n8n.

## Nodes
**FaxToFax**
- Send Fax: a file from a previous node, a file URL, text, and/or a cover note
- Get Fax Status
- List Faxes
- Download Fax PDF

**FaxToFax Trigger**
- New Fax Received
- Fax Delivered or Failed
